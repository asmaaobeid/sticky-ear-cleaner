# Sticky Ear Cleaner / My Ear Glow

## Run (site + admin API)

```bash
cd sticky-ear-cleaner
npm install
npm run dev
```

- Site: http://localhost:5173/
- Admin: http://localhost:5173/admin
- Phone (same Wi‑Fi): http://192.168.1.7:5173/
- Admin password (default): `admin123`

## What admin can do

- View / update / delete customer orders (name, phone, address, pack)
- Edit offer prices and labels (EN + AR)
- Edit brand, Instagram, WhatsApp, hero, announce bar
- Change admin password

Orders are saved in `data/orders.json`.
Settings are saved in `data/settings.json`.
